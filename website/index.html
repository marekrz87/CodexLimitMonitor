Simple setup

Unzip. Run. Glance.

Sign in to the Codex desktop app, extract Codex Limit Monitor to a permanent folder, and launch the EXE. It reads available usage windows through the local Codex app-server. If a 5-hour limit is not returned for your account, the app shows a dash.
